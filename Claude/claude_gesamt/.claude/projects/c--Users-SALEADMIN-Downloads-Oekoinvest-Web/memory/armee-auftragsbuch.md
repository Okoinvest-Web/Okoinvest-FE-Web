**Why:** ausdrücklicher Wunsch vom 03.10.2026 – „wenn Website fertig, gleich alle Agenten auf die Plattform“.
**How to apply:** Details und Sicherheitsregeln stehen in `~/claude-browser/armee/auftragsbuch.md`. Nach Abschluss der Website-Wellen die Plattform-Armee ohne erneute Nachfrage starten; nur echte Inhaber-Entscheidungen (z. B. Architektur, Rechtliches) vorher einholen. Restore-/Angriffstests nur lokal mit Demo-Daten. Siehe [[browser-screenshots]].
